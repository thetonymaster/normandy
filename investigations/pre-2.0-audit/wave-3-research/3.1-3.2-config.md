## 0. Surprises / risks (read first)

1. **Name collision on `circuit_breaker`.** `BaseAgentConfig.circuit_breaker` (base_agent_config.ex:72) is the *pid* the loop calls (`base_agent.ex:414-415`), and `ConfigTemplate` treats `:circuit_breaker` as a node-local field (config_template.ex:46, `AgentTemplate.supplement` `optional(:circuit_breaker)` agent_template.ex:23). The planned init option `circuit_breaker: keyword | nil` is the *opposite type* of the struct field of the same name. Plan must decide: keep struct field as pid and translate init `circuit_breaker: kw` -> started pid, or rename the struct field. Same for `retry`: struct field is `retry_options` (config_template `@data_fields`, base_agent.ex:407-430 read it); template persists it as `:retry_options`.
2. **Templates persist struct field names as top-level keys** (`@data_fields`, config_template.ex:28-39, merged via `Map.take(Map.from_struct(c), @data_fields)` at :87 and read back with `struct(Map.take(tmpl, @data_fields))` at :159). If struct fields are reshaped (guardrails kw), templates saved by the *unreleased 2.0 dev* branch (post commit 192addb) carry `retry_options`, `input_guardrails`, `output_guardrails`, `output_guardrails_*`; v1.0.0 templates carry NONE of those (see §6). "1.x translation" therefore = v1.0.0 shape (no retry/guardrail keys) + dev-branch shape; both need handling or an explicit decision to treat dev-branch as unsupported.
3. **Compactor opts live INSIDE `behaviours_refs.compactor` = `{module, opts}`** in the persisted template (config_template.ex:67, :137). Renaming `:max_tokens`->`:context_window` means rebuild/3 must rewrite opts inside that tuple (the opts may belong to a *custom* compactor module, e.g. test `KeepLastCompactor, keep: 2, max_tokens: 200_000`; blind rename of a third-party compactor's `:max_tokens` could be wrong; only `Compactor.WindowManager` is ours).
4. **Template atoms are decoded with `binary_to_term(_, [:safe])`** (session_store/codec.ex:19,23; redis.ex:175). Atoms for new keys (`:context_window`, `:guardrails`, ...) exist at decode time only if the module referencing them is loaded; old-key atoms (`:session_store`, `:session_registry`) must still exist after deleting the struct fields — they will, as long as some loaded module still mentions them (rebuild's translation code will). Test at config_template_test.exs:335-346 documents the `Static` precedent.
5. **`deprecated: session_store` in `from_config` writes `behaviours_refs.session_store/session_registry`** (config_template.ex:70-71) and `rebuild` reads them with strict `refs.session_store` (:139-140, KeyError if absent). After removal, rebuild must no longer require them, and `from_config` must stop emitting them (otherwise new templates carry dead keys).
6. **Tests: 213 `BaseAgent.init(` call sites in 70 test files.** A literal-map scan (AST, scratchpad keys.exs) of every `BaseAgent.init(%{...})` literal under test/, lib/, examples/ found **zero keys outside the current allowed set** (V). Non-literal args (`config` variables, `base_config(%{...})` helpers, `Map.put(base, ...)`) were not scanned. But many tests use keys that Task 3.2 renames: `retry_options` (≈9 files), `enable_circuit_breaker`/`circuit_breaker_options` (≈8 uses), `output_guardrails_streaming_mode`/`_chunk_size`/`_on_violation`, `input_guardrails`/`output_guardrails` (e.g. test/agents/base_agent_admit_test.exs:51). `session_id:` used ~35 times in tests — it is NOT in the `config_input` type (base_agent.ex:48-77) but IS read by init (:175): must be in the NimbleOptions schema.
7. **`check_run_opts!/1` deferred minor is partly stale.** `Keyword.keys([1,2])` raises `ArgumentError "expected a keyword list, but an entry in the list is not a two-element tuple with an atom as its first element, got: 1"` (V, ran elixir -e) — not an unhelpful FunctionClauseError, but it does not name `run/3`. `run/3` guard `when is_list(opts)` lets it through.
8. **window_manager.ex minor is in `Behaviours.Compactor.WindowManager`, not `Context.WindowManager`** — see §4 for exact failure modes (a `max_tokens: nil` opt reaches `reserved >= window` with nil; Erlang term order makes `int >= nil` TRUE, so the raise says "...smaller than the context window ()", misleading).
9. nimble_options 1.1.1 is already locked as a transitive dep (finch, redix) — adding `{:nimble_options, "~> 1.1"}` to mix.exs is needed to make it a direct dep (`mix deps.unlock --check-unused` fine either way).
10. DSL.Agent has its own duplicated key list `@override_keys` (dsl/agent.ex:391-417) containing every key to be renamed; plus compile-time attrs `:agent_input_guardrails` etc. (dsl/agent.ex:310-361, 466-497, 635-648). Task 3.2 must update DSL build_config + `@override_keys`, and DSL `validate_overrides!` (:421+) becomes redundant/duplicated with init strictness.

    # Validate guardrail config BEFORE starting the circuit breaker process;
    # otherwise a bad config would leak a linked breaker before we raise.
    input_guardrails = Map.get(config, :input_guardrails, [])
    output_guardrails = Map.get(config, :output_guardrails, [])

      raise ArgumentError,
            "input_guardrails must be a list of guard specs, got: #{inspect(input_guardrails)}"
    end

      raise ArgumentError,
            "output_guardrails must be a list of guard specs, got: #{inspect(output_guardrails)}"
    end

    streaming_mode = Map.get(config, :output_guardrails_streaming_mode, :accumulate)
    chunk_size = Map.get(config, :output_guardrails_chunk_size, 200)

    unless streaming_mode in [:accumulate, :incremental] do
      raise ArgumentError,
            "output_guardrails_streaming_mode must be :accumulate or :incremental, got: #{inspect(streaming_mode)}"
    end

    unless is_integer(chunk_size) and chunk_size > 0 do
      raise ArgumentError,
            "output_guardrails_chunk_size must be a positive integer, got: #{inspect(chunk_size)}"
    end

    on_violation = Map.get(config, :output_guardrails_on_violation, :block)

    unless on_violation in [:block, :warn] do
      raise ArgumentError,
            "output_guardrails_on_violation must be :block or :warn, got: #{inspect(on_violation)}"
    end

    tool_context = Map.get(config, :tool_context, %{})

    unless is_map(tool_context) do
      raise ArgumentError,
            "tool_context must be a map of plain data, got: #{inspect(tool_context)}"
    end

    _ =
      validate_compaction_config!(%BaseAgentConfig{
        client: Map.get(config, :client),
        behaviours: Map.get(config, :behaviours, nil)
      })

    _ = validate_client_options!(Map.get(config, :client))
    :ok = validate_policy_opts!(Map.get(config, :behaviours))
    :ok = validate_hooks!(Map.get(config, :behaviours))

      nil -> :ok
      retry_options -> Retry.validate_options!(retry_options)
    end

        cb

      end

      tool_registry: Map.get(config, :tool_registry, nil),

      max_tool_concurrency:
        normalize_max_tool_concurrency(Map.get(config, :max_tool_concurrency, 1)),
      retry_options: Map.get(config, :retry_options, nil),
      circuit_breaker: circuit_breaker,
      enable_json_retry: Map.get(config, :enable_json_retry, true),
      json_retry_max_attempts: Map.get(config, :json_retry_max_attempts, 2),
      mcp_servers: Map.get(config, :mcp_servers, nil),
      name: Map.get(config, :name, nil),
